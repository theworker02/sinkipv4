# sinkipv4

Sink filesystem ipv4 paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/sinkipv4/

## Install / run

```bash
git clone https://github.com/theworker02/sinkipv4.git
cd sinkipv4
node src/cli.js
node --test
```
